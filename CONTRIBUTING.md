# Contributing

Genitem is a research tool built by a small team. Feedback is welcome, and a
useful contribution does not need to be code: a clearer explanation, a
corrected translation or a report of something confusing on the website all
help.

## How to take part

- **Report a problem or suggest an idea** by opening an issue in this
  repository, or by writing to <info@genitem.education>.
- **Translations.** The website is available in six languages (English,
  French, Spanish, German, Portuguese and Italian). Corrections from native
  speakers are especially welcome.
- **Research use.** If you use Genitem in a study, we would be glad to hear
  about it. Please cite it as shown in the README.
