Test de modèles IA

Soumettre la même consigne à plusieurs modèles installés, puis comparer ce qu’ils produisent et le temps qu’ils y mettent — pour choisir en connaissance de cause plutôt qu’à l’estime.

Conditions générales
Reprend telles quelles les règles de l'Agent 1 (générateur d'items) du configurateur principal — seuls le thème et le nombre d'items se règlent ici. Le raisonnement (thinking) reste désactivé pour tous les modèles testés, sans possibilité de le réactiver.
Modèles à tester
Cliquez sur un modèle pour l'ajouter ou le retirer du test (surligné = inclus). Les modèles doivent déjà être installés au préalable (ollama pull).
Générer le script de test
Démarrer Ollama
À exécuter dans PowerShell, si Ollama n'est pas déjà lancé.
Lancer le test
À exécuter juste après, une fois test_modeles.txt enregistré dans le dossier \projet\. Ne pose aucune question : le thème, le nombre d'items et les modèles sont déjà inclus dans le fichier exporté.
⚠️ Le résultat s'enregistre dans un fichier resultats_modeles_AAAAMMJJ_HHMMSS.txt, dans le dossier \projet\ ⚠️
